Install the Edits skill

Claude needs it to run a brief through the crew: research, script, storyboard, look, animation, edit, sound, finish and a critic. One command in Terminal:

mkdir -p ~/.claude/skills && curl -fsSL https://sanjay-b-chauhan.github.io/github-project/edits/edits-skill.zip -o /tmp/edits-skill.zip && unzip -o /tmp/edits-skill.zip -d ~/.claude/skills
Download zip
  1. Run the command once.
  2. Build a brief in Compose and press Copy brief.
  3. Paste it into Claude Code. The skill runs every stage and stops at the two gates.
