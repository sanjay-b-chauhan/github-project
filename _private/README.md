# Private

Anything in this folder is deliberately kept out of the published site.

GitHub Pages runs Jekyll, and Jekyll ignores directories whose name starts
with an underscore — so these files stay in the repository but are never
served at the github.io address.

`vision-board.html` lives here. It is served from its own private
repository instead. Copyright (c) 2026 Sanjay Chauhan, all rights reserved.
